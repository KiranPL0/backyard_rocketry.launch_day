# Backyard Rocketry: Launch Day 
for my computer science class


## variables
goal - types:
max_alt - maximum altitude (ft)
max_v - maximum velocity (m/s), magnitude
max_v_x - maximum velocity (m/s), x-axis
max_v_y - maximum velocity (m/s), y-axis
max_acc - maximum acceleration (m/s^2), magnitude
max_acc_x - maximum acceleration (m/s^2), x-axis
max_acc_y - maximum acceleration (m/s^2), y-axis
launch_with - rocket must contain specific component (engine/<engine name>) or (structural/<component name>)

## TO PUT IN HOW 2 PLAY:
control surface - component that allows rocket to be controlled by you
-> if your rocket has atleast one component with a control surface, you'll be able to use the [A] and [D] keys to control your rocket's angle
ending flight early
-> if it's too long to fall back to the ground, press the [E] button while in flight to end the flight early
